# Store assets

Screenshots, icon and description for the EvenHub listing.

## Why images live here, when [[F-030]] says they do not

F-030 keeps frames, stills and captured subtitles out of these repositories.
Its reason is copyright: those were stills from a commercial episode, in a
public repo. It is not a rule about image files, it is a rule about other
people's media.

The captures here are from **Tears of Steel**, which is not that. They are the
one class of exception the finding's own reasoning allows, and this folder is
the allowlist.

Anything added here must clear the same bar: freely licensed, attributed
below. A frame from whatever happened to be playing does not go in, however
good it looks.
